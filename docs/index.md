### Bot Features

Pootis-Bot is Modular, making it easier to expand. Comes pre-included with these modules:

- Basic Bot Stuff
    - (Hello, ping, help, etc)
- AutoVC
    - Allows for a voice channel to automatically create smaller sub chats
- Profiles
    - XP, levels
- Rule Reaction
    - Require a message to be reacted to gain entry
- Welcome & Goodbye Message
    - Set a custom welcome and goodbye message for when your users join and leave

### Hosting

This bot is designed to be hosted by you, its not something you can just add. Please see [getting started](articles/) to start hosting.
